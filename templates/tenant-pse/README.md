# PSE tenant callers

Generated by `scripts/render_tenant.py`. Do not edit these files in a tenant repository and leave the generator behind. The platform repository owns the promotion logic. These callers only choose the tenant slug and the branches that start each workflow.

Regenerate:

```bash
python3 scripts/render_tenant.py \
  --tenant pse \
  --platform-repository OWNER/platform-workflows \
  --platform-ref v1 \
  --output templates/tenant-pse
```

Pin `--platform-ref` to a release tag before rolling the callers out to all 16 repositories. Use `main` only for the first personal-account demonstration.

Apply rulesets for a repository that uses these callers with `--caller-style reusable`. GitHub reports those checks as `promotion-policy / promotion-policy` and the same form for the other jobs. Confirm that string on the first pull request, then apply.
